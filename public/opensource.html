Components shipped in firmware

The following list covers the major OSS components. A full Software Bill of Materials (SBOM) is available on request.

  • OpenWrt — base Linux distribution. License: GPL-2.0. openwrt.org
  • Linux kernel — License: GPL-2.0.
  • BusyBox — Userland utilities. License: GPL-2.0.
  • Knot Resolver — Caching DNS resolver, content filtering. License: GPL-3.0. knot-resolver.cz
  • Lua — Embedded scripting. License: MIT.
  • lsqlite3 — SQLite Lua binding. License: MIT.
  • SQLite — Embedded database. License: Public Domain.
  • iptables / nftables — Packet filtering. License: GPL-2.0.
  • dnsmasq — DHCP/DNS forwarder. License: GPL-2.0.
  • wireguard-tools — VPN tunneling. License: GPL-2.0.
